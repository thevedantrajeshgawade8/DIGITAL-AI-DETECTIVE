Investigation progress

    Built to explain, not just label

    Every verdict comes with its reasons and its sources.

    ⌕

    Claim extraction

    Reads text and screenshots, then splits them into individual, testable claims.

    ◎

    Live evidence

    Each source keeps its title, link, snippet and retrieval time so you can check it.

    ⚖

    Four clear statuses

    Verified, contradicted, unverified and suspicious stay separate, never blended.

    ▲

    Explainable risk score

    Rule-based indicators add up to a score. It is not a probability of fraud.

    Honest by design

    Swipe through what the tool promises and what it won’t.

    Unknown stays unknown

    If no reliable source is found, the claim is marked unverified, not guilty.

    No invented citations

    Only links the system actually retrieved can appear in a report.

    Screenshots are data

    Text inside an image is never treated as instructions.

    Keys stay private

    API keys live on the backend. This page never holds them.

    No warning signs isn’t proof

    A clean result does not prove a message is legitimate.
